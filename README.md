# KRESZ B — тренажер HU/UA, офлайн

Особистий некомерційний вебзастосунок (PWA) для підготовки до теоретичного іспиту з ПДР Угорщини
(KRESZ), категорія B. Працює повністю офлайн на телефоні, мови — угорська й українська.

> Питання в застосунку сформульовано самостійно на основі тексту KRESZ
> (1/1975. (II. 5.) KPM–BM együttes rendelet). Це **не** офіційні екзаменаційні питання KAV.

## Що вміє

| Режим | Що робить |
| --- | --- |
| **Практика** | Питання за темами по одному; після відповіді одразу пояснення й пункт KRESZ. |
| **Картки** | Знаки, терміни, правила. Інтервальне повторення (система Лейтнера, 5 коробок), окрема колода «Мої помилки». |
| **Іспит на час** | Випадкова вибірка з усіх тем, таймер, без підказок; у кінці бали, «склав / не склав» і розбір помилок. |
| **Статистика** | Прогрес і точність за темами, слабкі теми, історія іспитів, картки за коробками. |

Мова перемикається кнопками **HU / UA / HU+UA** у шапці. У режимі HU+UA угорський текст основний,
український — під ним. Теми: світла, темна, системна. Прогрес зберігається лише на пристрої
(localStorage); у налаштуваннях його можна зберегти у файл і завантажити назад.

## Як запустити

Потрібен Node.js 22+.

```bash
npm install
npm run dev        # режим розробки: http://localhost:5173
npm run build      # збірка в dist/
npm run preview    # перегляд збірки (тут працює service worker й офлайн)
npm test           # тести логіки + перевірка контенту
npm run lint
```

Щоб перевірити офлайн: `npm run build && npm run preview`, відкрий сторінку, дочекайся повідомлення
«Az alkalmazás offline is használható», потім вимкни мережу (DevTools → Network → Offline) і перезавантаж.

На телефоні: відкрий сайт у Chrome → меню → «Додати на головний екран» (на iPhone: Safari →
«Поділитися» → «На початковий екран»).

## Структура

```
src/
  app/            App, hash-роутер, макет із нижньою навігацією
  components/     QuestionView, перемикач мови, базові елементи
  config/
    exam.ts       ← усі параметри іспиту в одному місці (з джерелом)
    practice.ts   розмір раунду, поріг «слабкої теми»
  content/
    topics.json   список тем
    decks.json    список колод карток
    questions/    питання: один JSON-файл на тему
    cards/        картки: один JSON-файл на колоду
  features/       practice/, cards/, exam/, stats/, settings/, home/
  i18n/           hu.json, ua.json — усі тексти інтерфейсу
  signs/          дорожні знаки, схеми перехресть і світлофори власними SVG-компонентами
  store/          прогрес, налаштування, поточний іспит (localStorage)
```

## Як додати питання

Відкрий файл теми в `src/content/questions/` (наприклад, `speed.json`) і додай об'єкт у масив:

```json
{
  "id": "speed-011",
  "topic": "speed",
  "kreszRef": "KRESZ 26. § (5)",
  "image": "speedLimit50",
  "points": 1,
  "hu": {
    "question": "…?",
    "answers": ["helyes válasz", "rossz válasz", "rossz válasz"],
    "explanation": "…"
  },
  "ua": {
    "question": "…?",
    "answers": ["правильна відповідь", "хибна відповідь", "хибна відповідь"],
    "explanation": "…"
  },
  "correct": 0
}
```

Правила:

- `id` — унікальний; `topic` — id теми з `topics.json` і водночас назва файлу.
- `answers` в `hu` і `ua` йдуть **в однаковому порядку**; `correct` — індекс правильної (з нуля).
  Порядок у файлі не важливий: застосунок перемішує відповіді під час показу.
- `image` (необов'язково) — id малюнка: дорожній знак, схема перехрестя (`x-…`) або сигнал
  світлофора (`light-…`). Усі доступні id видно на службовій сторінці `#/signs`
  (наприклад, `http://localhost:5173/#/signs`).
- `points` (необов'язково) — вага на іспиті: `1` (типово) або `3`.
- Після змін запусти `npm test` — тест перевірить структуру, обидві мови, id тем і малюнків.

**Нова тема:** додай запис у `src/content/topics.json` і створи `src/content/questions/<id>.json`.

**Картки:** так само в `src/content/cards/<колода>.json` (`id`, `deck`, `hu`/`ua` з `front` і `back`,
необов'язково `image` і `kreszRef`). Для картки-знака `front` можна лишити порожнім — показується малюнок.

**Новий знак:** додай функцію в `src/signs/registry.tsx` (SVG у полі 100×100) — id одразу стане
доступним для `image`.

**Нова схема перехрестя:** додай запис у `SCENES` у `src/signs/scenes.tsx` — схема описується
декларативно: які дороги є (`arms`), які з них ґрунтові (`dirt`), хто звідки й куди їде
(`vehicles`), які знаки стоять (`signs`). Синій автомобіль — це завжди «Ви».

**Тексти інтерфейсу:** `src/i18n/hu.json` і `src/i18n/ua.json`. Ключі в обох файлах мають збігатися —
інакше збірка не пройде.

## Параметри іспиту

Усі параметри — у `src/config/exam.ts`.

| Параметр | Значення | Статус |
| --- | --- | --- |
| Кількість питань | 55 | перевірено |
| Час | 55 хв | перевірено |
| Максимум балів | 75 | перевірено |
| Прохідний поріг | 65 | перевірено |
| Розподіл балів (10 питань × 3 + 45 × 1) і які теми «трибальні» | — | **неперевірено** |
| Ліміт часу на окреме питання, повернення до попередніх питань | — | **неперевірено** |

Джерело: KAV Közlekedési Alkalmassági és Vizsgaközpont, «Tantervi és vizsgakövetelmények a „B”
kategóriás járművezető-képző tanfolyamok számára» (2023), розділ VII. A. Közlekedési alapismeretek —
<https://vizsgakozpont.hu/uploads/2023/dokumentumok/tantervi_es_vizsgakov_b_kategoria_2023_alairt.pdf>
(перевірено 22.11.2026). Перед іспитом варто глянути на vizsgakozpont.hu, чи немає новішої редакції.

Текст правил: Nemzeti Jogszabálytár, 1/1975. (II. 5.) KPM–BM együttes rendelet —
<https://njt.jog.gov.hu/jogszabaly/1975-1-20-24>.

## Як задеплоїти (GitHub Pages)

Деплой налаштовано в `.github/workflows/deploy.yml`: на кожен push у `main` проганяються лінтер,
тести й збірка, після чого `dist/` публікується на GitHub Pages. Base path береться з назви
репозиторію автоматично (`/kresz/`).

Один раз потрібно ввімкнути Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Після цього злий зміни в `main` — сайт з'явиться на `https://<користувач>.github.io/kresz/`.

Для іншого хостингу досить `npm run build` (base `/`) або `BASE_PATH=/підпапка/ npm run build`.
